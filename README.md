# HAi Service — preview

Sitio compilado de **HAi Service**, la web de la tienda: servicio técnico
(móviles, portátiles, PC, consolas, patinetes y microsoldadura) y fundas
personalizadas.

👉 **https://nstor6.github.io/hai-service-preview/**

Este repositorio contiene **solo el resultado del build** (HTML, CSS y JS
compilados). El código fuente está en un repositorio privado.

## Qué es y qué no es

- Es una **vista previa para revisar diseño y textos**, no la web en producción.
- Está marcada como `noindex`: no aparece en Google. No la enlaces desde
  ninguna parte pública.
- **Los formularios no envían nada todavía.** Falta conectar el proyecto de
  Firebase, así que "Pedir presupuesto" y "Contacto" no guardan la solicitud
  ni mandan emails.
- **Los datos de la tienda son de relleno**: dirección, teléfono, email y
  horario son inventados hasta tener los reales.
- **No hay ningún precio** en toda la web, a propósito: aún está por decidir.

## Qué se puede revisar ya

Navegación y textos de inicio, `/reparaciones` y cada categoría,
`/presupuesto`, `/contacto`, `/fundas` y las páginas legales. También cómo
queda en móvil.

Fase 1 de 6 (web de servicio y solicitudes de presupuesto). Pendientes:
